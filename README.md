## 🚀 Inicialização Soberana

Cada módulo pode ser executado de forma autônoma ou integrado em um orquestrador central.

```python
from modules.nectar_market import NectarMarket
from modules.nectar_intelligence import NectarIntelligence

async def main():
    market = NectarMarket()
    intel = NectarIntelligence()
    
    # Colher Néctar
    nectar = await intel.recursive_harvest("https://lmsys.org/blog/")
    
    # Analisar Arbitragem
    opp = await market.analyze_predatory_opportunity("SOL", {"Binance": 145, "Kraken": 146})
    print(opp)

if __name__ == "__main__":
    import asyncio
    asyncio.run(main())
```
